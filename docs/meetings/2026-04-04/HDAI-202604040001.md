## 2. 안건

### 2.1 Frontend 기술 스택 선정

- **내용**: 사용자 웹 클라이언트(번역기 + 게시판)에 사용할 프론트엔드 기술 스택 논의
- **논의사항**: 
  - **1차 목표**: TypeScript 기반으로 프론트엔드 구현
  - **대안**: 기능 구현 우선을 위해 Streamlit(Python)으로 먼저 프로토타입할 가능성도 논의
  - ⚠️ **확인 필요**: Streamlit으로 게시판(CRUD) 기능 구현이 가능한지 사전 검증 필요
  - **디자인**: https://html5up.net 에서 템플릿을 선택하여 디자인 베이스로 활용하기로 함
- **결론**: 
  - **1차 목표**는 **TypeScript 기반** 프론트엔드
  - 빠른 기능 검증이 필요한 경우 **Streamlit** 프로토타입도 고려 (게시판 가능 여부 확인 후 결정)
  - 디자인은 HTML5 UP 템플릿 기반으로 진행

### 2.2 Backend 기술 스택 선정

- **내용**: API 서버 및 AI 파이프라인에 사용할 백엔드 기술 스택 논의
- **논의사항**: 
  - FastAPI(Python) 기반 백엔드 구성이 유력
  - OCR(PaddleOCR) 및 AI 모델 연동에 Python 생태계가 유리
- **결론**: FastAPI(Python) 방향으로 논의 중 (세부 사항 추후 확정)

### 2.3 데이터베이스 및 인프라

- **내용**: 데이터베이스 및 배포 환경 논의
- **논의사항**: 
  - DB 후보: **PostgreSQL** 또는 **MariaDB** — PostgreSQL 쪽으로 가능성 높게 보고 있음
  - 인프라: **Docker** 기반으로 진행할 가능성 높음
- **결론**: PostgreSQL 유력, Docker 활용 방향. 최종 확정은 추후 진행

### 2.4 외부 서비스 (OCR / AI 모델)

- **내용**: OCR 엔진 및 AI 번역 모델 선정
- **논의사항**: 아직 구체적으로 논의되지 않음 (SRS 기준 PaddleOCR + Gemini Flash 예정)
- **결론**: 추후 논의 예정
