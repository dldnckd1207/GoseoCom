## 목표

Google / Kakao OAuth 2.0 로그인 구현. JWT + httpOnly 쿠키로 Stateless 인증 유지 및 XSS 방어. Refresh Token Rotation으로 탈취 감지.

## 성공 기준

- [ ] Google / Kakao OAuth 로그인 성공 → httpOnly 쿠키 발급
- [ ] 재로그인 시 UPSERT (신규 생성 아님)
- [ ] Refresh Token 갱신 → 새 토큰 발급, 이전 revoked
- [ ] 로그아웃 → 쿠키 삭제 + token revoked
- [ ] `/api/v1/users/me` 인증 확인
- [ ] `@require_level` 데코레이터 동작
- [ ] `/auth/dev/token` dev 환경만 활성화
- [ ] login_log 성공/실패 기록
- [ ] USR_00000000 시드 데이터 마이그레이션
- [ ] 탈퇴 90일 이내 재로그인 차단
