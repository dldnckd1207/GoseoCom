## 1. 목표

FastAPI 기반 다중 게시판 관리 BE 구현.
`board_code`(slug)로 식별되는 게시판을 CRUD하고, 클라이언트(GUEST/USER)와 관리자(ADMIN)의 접근 권한을 분리한다.

---

## 2. 배경 및 범위

- 서비스는 번역(`translation`), 질문(`questions`), 자유(`free`) 3종 게시판을 운영한다.
- 각 게시판은 댓글·첨부·AI 자동 답변 등 독립적인 설정을 가진다.
- Phase 1: API 구현 + seed 데이터. Admin UI 없음(Swagger로 관리).
- Phase 3: Admin UI 연동.

---

## 3. 핵심 요구사항

### 클라이언트 API (`/api/v1/`)
- GUEST/USER Optional 인증 분기
- `POST /api/v1/boards/list` — 경량 목록 (탭 렌더링용)
  - 비회원: `guest_read_yn=true` 필터
  - 로그인: `read_yn=true` 필터
- `GET /api/v1/boards/{board_code}` — 전체 설정 단건 조회
  - 비회원 + `guest_read_yn=false` → 403

### 관리자 API (`/admin/api/v1/`) — ADMIN 전용
- `POST /admin/api/v1/boards/list` — 전체 목록 (비활성 포함)
- `GET /admin/api/v1/boards/{board_id}` — 단건 조회
- `POST /admin/api/v1/boards` — 생성 (board_code 중복 체크)
- `PUT /admin/api/v1/boards/{board_id}` — 수정
- `DELETE /admin/api/v1/boards/{board_id}` — Soft Delete (게시글 있으면 409)

### DB
- `cms_tn_board` 권한 컬럼 추가: `read_yn`, `guest_read_yn`, `write_yn`, `guest_write_yn`, `category_yn`
- `cms_tn_board_category` 신규 (Phase 3 선반영)
- `cms_tn_post.category_id` 추가

### Seed
- 기본 게시판 3개: translation / questions / free

---

## 4. 제약 조건

- 프레임워크: FastAPI + SQLAlchemy 2.x async
- DB: PostgreSQL 16 (`cms_tn_board`, ID-Gen `BRD_`)
- 인증: `require_level(UserRole.ADMIN)` / `require_level(UserRole.GUEST)`
- Soft Delete: `del_yn=true` (물리 삭제 없음)
- `secret_yn`, `like_yn`: Phase 1 API 노출 안 함 (고정 false)
- `board_code` Phase 1 변경 금지 정책 (미결 사항)

---

## 5. 성공 기준

| 항목 | 기준 |
|------|------|
| GUEST 목록/단건 조회 | 200 정상 |
| ADMIN 생성 | 201, `BRD_XXXXXXXX` ID 발급 |
| board_code 중복 | 409 `BOARD_CODE_ALREADY_EXISTS` |
| ADMIN 수정 | 200, 변경 필드만 반영 |
| 게시글 없는 삭제 | 200 DELETED, 목록 미노출 |
| 게시글 있는 삭제 | 409 `BOARD_HAS_POSTS` |
| 없는 board_id | 404 `BOARD_NOT_FOUND` |
| 비로그인 ADMIN API | 401 UNAUTHORIZED |
| del_yn=true 게시판 조회 | 404 BOARD_NOT_FOUND |
