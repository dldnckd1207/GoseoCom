## 1. 아키텍처

```
apps/server/
├── alembic.ini                  # sqlalchemy.url → env.py에서 override
├── alembic/
│   ├── env.py                   # async 마이그레이션 설정, settings.database_url 주입
│   └── versions/
│       └── xxxx_init.py         # 빈 마이그레이션 (테이블 정의 없음)
└── app/
    ├── config.py                # Settings → database_url 생성
    └── db/
        ├── base.py              # DeclarativeBase
        └── session.py           # AsyncEngine, AsyncSessionLocal
```

---

## 2. DB 연결 설계

### 접속 정보 흐름

```
.env
 └── POSTGRES_HOST / PORT / DB / USER / PASSWORD
      └── app/config.py (Settings.database_url)
           └── alembic/env.py (config.set_main_option)
                └── create_async_engine → PostgreSQL 연결
```

### DSN 형식

```
postgresql+asyncpg://{user}:{password}@{host}:{port}/{db}
```

---

## 3. Alembic 설계

### env.py 핵심 설계

| 항목 | 내용 |
|------|------|
| 실행 방식 | async (`asyncio.run`) |
| DSN 주입 | `settings.database_url` → `config.set_main_option` |
| target_metadata | `Base.metadata` (현재 빈 상태) |
| 모델 import | 각 도메인 `models.py` import (현재 빈 파일) |

### 마이그레이션 실행 흐름

```
1. uv run alembic revision --autogenerate -m "init"
   → alembic/versions/{hash}_init.py 생성
   → 모델이 비어있으므로 upgrade/downgrade 함수 내용 없음

2. uv run alembic upgrade head
   → PostgreSQL에 alembic_version 테이블 생성
   → 현재 revision hash 기록

3. uv run alembic current
   → 현재 적용된 revision 출력으로 성공 확인
```

## 4. 검증 방법

| 검증 항목 | 명령어 | 기대 결과 |
|----------|--------|---------|
| DB 연결 확인 | `uv run python -c "from app.config import settings; print(settings.database_url)"` | DSN 출력 |
| revision 생성 | `uv run alembic revision --autogenerate -m "init"` | versions/ 파일 생성 |
| 마이그레이션 실행 | `uv run alembic upgrade head` | 에러 없음 |
| 적용 확인 | `uv run alembic current` | revision hash 출력 |

---

## 5. 주의사항

- `alembic.ini`의 `sqlalchemy.url`은 더미값으로 두고 `env.py`에서 override — 실제 접속 정보는 `.env`에만 존재
- 빈 마이그레이션이므로 `upgrade` 함수 내부가 `pass`여도 정상
- 이후 SFR별로 모델 추가 시 `alembic revision --autogenerate` 재실행하여 테이블 추가
