## 코드 구조

```
app/auth/
  ├── router.py          # /auth/* 엔드포인트
  ├── service.py         # 비즈니스 로직 (rotation, UPSERT 등)
  ├── repository.py      # DB 쿼리 (user, oauth, token, login_log)
  ├── schemas.py         # Request/Response Pydantic 모델
  └── oauth/
      ├── google.py      # Google OAuth 플로우 (state 생성/검증 포함)
      └── kakao.py       # Kakao OAuth 플로우 (state 생성/검증 포함)

app/core/
  ├── security.py        # JWT 서명/검증, HMAC-SHA256 토큰 해시 (공통 모듈)
  └── common/decorators/
      └── require_level.py  # @require_level(UserRole.USER)
```

## OAuth state 파라미터 (CSRF 방어)

```
1. /auth/google 요청 시 → 서버가 랜덤 state 생성 → 서명된 쿠키에 저장
2. Provider로 리다이렉트 시 state 파라미터 포함
3. 콜백에서 쿠키의 state와 쿼리의 state 비교 → 불일치 시 400 반환
→ authlib이 내부적으로 처리 (OAuth2Session의 state 관리)
```

## Refresh Token Rotation — Grace Period

```
동시 요청(다중 탭/기기) 레이스 컨디션 방지:
- is_revoked=true 처리 후 30초 grace period 부여
- grace period 내 동일 token_hash 재요청은 탈취 감지 아닌 정상 처리
- grace period 초과 후 revoked 토큰 재사용 → TOKEN_REUSE_DETECTED
```

## API 엔드포인트

| Method | Path | 설명 |
|--------|------|------|
| GET | `/auth/google` | Google OAuth 시작 (state 생성) |
| GET | `/auth/google/callback` | Google 콜백 (state 검증) |
| GET | `/auth/kakao` | Kakao OAuth 시작 (state 생성) |
| GET | `/auth/kakao/callback` | Kakao 콜백 (state 검증) |
| POST | `/auth/refresh` | Access Token 갱신 |
| POST | `/auth/logout` | 로그아웃 (토큰 없어도 쿠키 삭제 후 200) |
| GET | `/api/v1/users/me` | 내 정보 조회 |
| POST | `/auth/dev/token` | 개발용 토큰 (dev only, 라우터 등록 자체를 조건 분기) |

## 쿠키 설정

- `access_token`: httpOnly, SameSite=Lax, Secure(운영), 1시간
- `refresh_token`: httpOnly, SameSite=Lax, Secure(운영), 30일

## 보안 처리

- **Refresh Token 해시**: HMAC-SHA256 (`app/core/security.py`)
- **JWT**: `PyJWT` 라이브러리 사용
- **dev 라우터**: `if settings.app_env == AppEnv.DEVELOPMENT: app.include_router(dev_router)`
- **만료 레코드 정리**: 배치로 `expires_at < now() - 7일` 삭제 (탈취 감지 보존 기간 확보)

## 의존성 추가

- `authlib` — OAuth 2.0 클라이언트 (state, PKCE 등 자동 처리)
- `PyJWT` — JWT 서명/검증 (python-jose 대체)
