## 1. 아키텍처

```
HTTP Request
  → FastAPI Router (router.py / admin_router.py)
  → require_level(UserRole.GUEST | ADMIN) Dependency
  → Service (BoardService)
  → Repository (BoardRepository)
  → PostgreSQL (cms_tn_board)
  → Pydantic Response Schema 반환
```

**레이어 분리:**
- `router.py` — 클라이언트 API (`/api/v1/boards/`)
- `admin_router.py` — 관리자 API (`/admin/api/v1/boards/`)
- `service.py` — 비즈니스 로직, commit
- `repository.py` — DB 쿼리 (flush만)
- `schemas.py` — Request/Response Pydantic 모델
- `models.py` — SQLAlchemy ORM

## 3. API 설계

### 클라이언트 (`/api/v1/`)

| Method | Path | 인증 | 설명 |
|--------|------|------|------|
| POST | `/api/v1/boards/list` | GUEST (Optional) | 경량 목록 |
| GET | `/api/v1/boards/{board_code}` | GUEST (Optional) | 전체 설정 단건 |

### 관리자 (`/admin/api/v1/`)

| Method | Path | 인증 | 설명 |
|--------|------|------|------|
| POST | `/admin/api/v1/boards/list` | ADMIN | 전체 목록 (비활성 포함) |
| GET | `/admin/api/v1/boards/{board_id}` | ADMIN | 단건 |
| POST | `/admin/api/v1/boards` | ADMIN | 생성 |
| PUT | `/admin/api/v1/boards/{board_id}` | ADMIN | 수정 |
| DELETE | `/admin/api/v1/boards/{board_id}` | ADMIN | Soft Delete |

### 에러 코드

| 코드 | HTTP | 상황 |
|------|------|------|
| BOARD_NOT_FOUND | 404 | 존재하지 않는 board |
| BOARD_CODE_ALREADY_EXISTS | 409 | board_code 중복 |
| BOARD_HAS_POSTS | 409 | 게시글 있는 게시판 삭제 시도 |
| FORBIDDEN | 403 | 비회원 + guest_read_yn=false |
| UNAUTHORIZED | 401 | 미인증 ADMIN API 호출 |
