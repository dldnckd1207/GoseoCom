## 1. 아키텍처

```
HTTP Request
  → FastAPI Router (post_router / comment_router)
  → require_level(GUEST | USER) Dependency
  → Service (PostService / CommentService)
  → Repository (PostRepository / CommentRepository / FileMapRepository)
  → PostgreSQL
  → Pydantic Response 반환
```

**레이어 역할:**
- `router`: 요청 수신, 권한 체크, Service 호출, ApiResponse 래핑
- `service`: 비즈니스 로직, board 정책 검증, commit(), 트랜잭션 관리
- `repository`: 순수 DB 쿼리, flush()만

## 2. 데이터 모델

기존 테이블 변경 없음. `cms_tn_post`, `cms_tn_comment`, `cms_th_post_history`, `com_tn_file`, `com_tn_file_map` 모두 이미 생성됨.

**JWT payload 변경 (기존 → 신규):**
```python
# 기존
{"sub": user_id, "level": user_level, "blocked": blocked, "exp": expire, "type": "access"}
# 신규
{"sub": user_id, "level": user_level, "name": user_name, "blocked": blocked, "exp": expire, "type": "access"}
```

**파일 업로드 저장 경로:**
```
storage/files/{YYYY}/{MM}/{uuid}.{ext}
```

## 4. 스키마 설계

### Post

```python
class PostListRequest(BaseModel):
    board_code: str = Field(..., description="게시판 코드")
    keyword: str | None = Field(None, description="제목 검색")

class PostSummaryResponse(BaseModel):  # 목록용 경량
    id: str
    board_id: str
    board_code: str
    author_name: str
    is_ai_gen: bool        # user_id == 'USR_00000000'
    title: str
    notice_yn: bool
    view_count: int
    comment_count: int
    created_at: datetime
    model_config = {"from_attributes": True}

class PostDetailResponse(BaseModel):  # 단건 전체
    id: str
    board_id: str
    board_code: str
    user_id: str
    author_name: str
    is_ai_gen: bool
    parent_id: str | None
    depth: int
    title: str
    content: str
    notice_yn: bool
    view_count: int
    comment_count: int
    auto_reply_status: str
    files: list[FileResponse]
    created_at: datetime
    updated_at: datetime
    model_config = {"from_attributes": True}

class PostCreateRequest(BaseModel):
    board_code: str
    title: str = Field(..., max_length=255)
    content: str
    notice_yn: bool = False
    parent_id: str | None = None
    file_ids: list[str] = Field(default_factory=list)

class PostUpdateRequest(BaseModel):
    title: str | None = Field(None, max_length=255)
    content: str | None = None
    notice_yn: bool | None = None
```

## 5. Repository 설계

### PostRepository

```python
class PostRepository:
    async def list(self, board_id, keyword, page, size) -> tuple[list[Post], int]
    async def get_by_id(self, post_id) -> Post | None
    async def create(self, post) -> Post
    async def update_view_count(self, post_id) -> None  # atomic UPDATE
    async def increment_comment_count(self, post_id) -> None  # atomic UPDATE
    async def decrement_comment_count(self, post_id) -> None  # atomic UPDATE WHERE > 0
    async def soft_delete(self, post, deleted_by) -> None
```

### PostHistoryRepository

```python
class PostHistoryRepository:
    async def get_last_version(self, post_id) -> int  # COALESCE(MAX(version), 0)
    async def insert(self, history) -> None
```

### CommentRepository

```python
class CommentRepository:
    async def list_roots(self, post_id, page, size) -> tuple[list[Comment], int]
    # del_yn 무관 root 조회 (placeholder 포함)
    async def list_replies_by_roots(self, root_ids) -> list[Comment]
    # del_yn=false replies만
    async def get_by_id_and_post(self, comment_id, post_id) -> Comment | None
    async def create(self, comment) -> Comment
    async def soft_delete(self, comment, deleted_by) -> None
```

### FileRepository (core/files)

```python
class FileRepository:
    async def get_by_id(self, file_id) -> File | None
    async def create(self, file) -> File
    async def get_by_uuid(self, uuid) -> File | None

class FileMapRepository (core/files):
    async def list_by_target(self, target_type, target_id) -> list[FileMap]
    async def soft_delete_all_by_target(self, target_type, target_id) -> None
    async def upsert(self, file_id, target_type, target_id, file_group="attachment", sort_order=0) -> None
    # (file_id, target_type, target_id) 기준 del_yn=false 복원 또는 INSERT
    # 게시글 첨부는 file_group="attachment" 기본값 사용
```

## 6. Service 설계

### PostService

```python
class PostService:
    async def list_posts(self, req, payload) -> PageData[PostSummaryResponse]
    async def get_post(self, post_id, payload) -> PostDetailResponse
    # board read_yn/guest_read_yn 검증, view_count atomic ++, files 조회
    async def create_post(self, req, payload) -> PostDetailResponse
    # board 정책 검증 → file_ids 검증 → INSERT → file_map INSERT → commit
    async def update_post(self, post_id, req, payload) -> PostDetailResponse
    # 권한 검증 → file_ids 사전 검증 → [트랜잭션] history + UPDATE + file_map 교체 → commit
    async def delete_post(self, post_id, payload) -> None
    # 권한 검증 → [트랜잭션] history(DELETE) + soft_delete → commit
    async def upload_file(self, board_code, file, payload) -> FileUploadResponse
    # board attach 정책 검증 → 파일 저장 → com_tn_file INSERT → commit

    def _validate_files(self, file_ids, board, user_id, user_level) -> list[File]
    # 중복 제거(dict.fromkeys), 존재·del_yn·소유권·정책 검증
    def _is_ai_gen(self, user_id) -> bool  # user_id == 'USR_00000000'
```

### CommentService

```python
class CommentService:
    async def list_comments(self, post_id, req, payload) -> PageData[CommentResponse]
    # post 확인 → board read_yn 검증 → root 조회(del_yn 무관) → replies IN 쿼리 → Nested 조립
    # del_yn=true root → placeholder 변환 (content, author_name, is_deleted)
    async def create_comment(self, post_id, req, payload) -> CommentResponse
    # post·board 확인 → comment_yn·depth·parent 검증 → INSERT → comment_count++ → commit
    async def update_comment(self, post_id, comment_id, req, payload) -> CommentResponse
    # (comment_id, post_id) 조회 → 권한 → UPDATE → commit
    async def delete_comment(self, post_id, comment_id, payload) -> None
    # (comment_id, post_id) 조회 → 권한 → soft_delete → comment_count-- → commit
```

## 7. Router 설계

### post_router.py — `/api/v1/posts/`

```python
router = APIRouter(prefix="/api/v1/posts", tags=["posts"])
board_router = APIRouter(prefix="/api/v1/boards", tags=["posts"])

POST   /api/v1/posts/list              → list_posts
GET    /api/v1/posts/{post_id}         → get_post
POST   /api/v1/posts                   → create_post (status=201)
PUT    /api/v1/posts/{post_id}         → update_post
DELETE /api/v1/posts/{post_id}         → delete_post
POST   /api/v1/boards/{board_code}/uploads → upload_file (status=201)
```

### comment_router.py — `/api/v1/posts/{post_id}/comments/`

```python
router = APIRouter(prefix="/api/v1/posts/{post_id}/comments", tags=["comments"])

POST   /list                           → list_comments
POST   ""                              → create_comment (status=201)
PUT    /{comment_id}                   → update_comment
DELETE /{comment_id}                   → delete_comment
```

### core/files/router.py — `/files/`

```python
router = APIRouter(prefix="/files", tags=["files"])

GET    /{uuid}                         → serve_file        (최종 경로: /files/{uuid})
GET    /{uuid}?download=true           → download_file     (최종 경로: /files/{uuid}?download=true, Content-Disposition: attachment)
```

## 8. 파일 업로드/서빙 설계

### 업로드 흐름

```python
# POST /api/v1/boards/{board_code}/uploads
# multipart/form-data: file
1. board 조회 → attach_yn 검증
2. file_ext, file_size, mime_type 추출
3. attach_ext(file_ext), attach_size(KB) 검증
4. uuid 생성 → storage/files/{YYYY}/{MM}/{uuid}.ext 저장
5. com_tn_file INSERT (id=FILE_, url_path=/files/{uuid})
6. FileUploadResponse 반환
```

### 서빙 흐름

```python
# GET /files/{uuid}
1. com_tn_file WHERE uuid=:uuid AND del_yn=false 조회
2. 없으면 → 404
3. local_path로 FileResponse 반환 (StreamingResponse)
```
