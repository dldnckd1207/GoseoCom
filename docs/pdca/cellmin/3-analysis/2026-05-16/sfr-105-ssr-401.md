## server.ts 최종 정책

```
optional/action → 401 시 ApiError(401) throw (refresh 없음)
required        → 401 시:
    refresh_token 없음  → redirect('/login?redirect=pathname+search')
    refresh 성공        → Response(302, Set-Cookie) → 브라우저 재요청
    refresh 실패        → redirect('/login?redirect=pathname+search')
    Set-Cookie 없음     → redirect('/login?redirect=pathname+search')
```
